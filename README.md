Проекты и артефакты

Моделирование процессов: диаграммы As‑Is и To‑Be (файлы «as is и to be») — для наглядного сравнения текущего и целевого состояния.
UML‑диаграммы: диаграмма классов и диаграмма объектов (.drawio) — формализуют структуру данных и связи между сущностями.
Документация: шаблоны требований и отчёта об обследовании (.docx) — соответствуют отраслевым стандартам и ускоряют запуск новых задач.
CJM для магазина (.docx) — карта пути клиента с выявленными болевыми точками и предложениями по улучшению.
Дополнительно: есть демонстрационное видео (mp4) — по запросу покажу разбор логики решения и обоснование ключевых изменений.
